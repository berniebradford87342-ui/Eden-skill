# 字段与使用说明

- **原题**：来源原题保留；文件名仅替换操作系统/链接不支持的字符，正文和原题属性保持原文。
- **状态**：初次入库均待人工选择。已评分方案为待选；其他为待补内容、合并参考、素材备查。选定后可改已选、制作中、已发布、已复盘。
- **目标 / 目标格式**：观众获得什么、建议采用什么形式；格式可自行调整。
- **添加日期**：入库日期；研究日期、原作发布时间另存，不混用。
- **参考视频**：原作链接；可能是视频或图文原帖。点击链接到原平台，未下载视频文件。
- **评分结果 / HD FIT DIF PRE HOOK COST SEO**：总分区间与七维评分；未知留空，零分与未知不同。详细理由在笔记正文。
- **预期命中**：当前七维中评分≥4的强项。这是显示规则，不是已验证预测模型或爆款概率。
- **预测判断**：与7.5试行参考线的位置关系，低于参考线仍可选。区间跨线表示证据尚有缺项。
- **预测验证**：当前“待发布验证”；发布后可改为“已复盘”。
- **实际命中结果**：发布后根据事先记录的目标、观察窗口及本账号基线填写有证据支持的判断；可记“命中／部分命中／未命中／基线不足／待验证”；现在留空。
- **原作点赞、收藏、评论、分享、播放**：同一次选定来源快照；保留来源口径。约3.6万保留约数说明，筛选时用36000近似数值。
- **粉丝快照**：第三方保存时点不明，不能当发布时粉丝，不计算伪“互动率”。
- **你的选择**：填写选用、暂缓或不用；在正文补理由。入库不表示自动选用。
- **发布链接、实际发布日期、复盘日期、实际指标**：留待真实发布和复盘填写。

## 使用

打开选题看板，切换视图或筛选内容线/状态；点击标题进入卡片。数据总表适合比较七维和编辑状态。先记录你的选择，选中后再修改状态。

所有卡片都是普通Markdown，数据存在frontmatter属性。卡片网格由原生Bases渲染。当前Obsidian 1.13.4使用卡片网格及分组，不依赖第三方看板插件。

## 后续入库

导入按原作URL生成稳定键，重复导入跳过已有卡片，避免覆盖你已写的选择、状态、讲法和复盘。新增作品会新增卡片；已有作品重新评分应保存新评分历史后明确更新，不静默覆盖。

来源说明：[Obsidian Bases卡片视图](https://help.obsidian.md/bases/views/cards)、[Bases语法](https://help.obsidian.md/bases/syntax)。

## 2026-10-19确认补充

- **时效类型**：常青科普／历史案例／近期热点；无法归类填待验证。独立于两条内容线，不新增第三条内容线；“近期热点”需当下升温依据，不能只看发布时间。时效判断依据保存原因。
- **关联对标**：链接到账号资料或单篇来源条目。单篇高赞作者不自动成为核心对标。
- **具体假设／假设状态**：基于已明确方案写出预计观众能理解或判断的具体内容；现在均待验证。没有方案的条目写待明确内容方案，不编造假设。
- **假设观察线索**：将来应收集什么反馈，不代表已有反馈。收藏、点赞不能独立证明理解；受众身份只依据主动自述等真实证据。
- **核验状态**：提示尚待验证；具体缺口见卡片取舍、来源及对标资料。三个月增长统一待验证，未知不补零。
- **复盘观察窗口／复盘比较基线／观众理解反馈／受众自述反馈／新增关注／观看留存记录**：发布后按实际填写；未发布留空。留存写平台定义及单位，无数据留空。多次观察追加记录，不混合不同时长数据。
- **实际命中结果**：现在留空；按证据记录结果与不确定性，不预设数值门槛。7.5是既有待校准评分参考线，不是效果门槛；原评分强项的≥4只是展示规则。

复盘入口就在每张卡片的“具体假设的发布后复盘”表格。未选用前不自动制作、排期或修改你的选择。
