# 账号配置

配置保存在用户的运行工作区，不能把私人画像、产品原始资料或接口配置提交到 Skill 仓库。复制 `assets/account.example.json` 后填写；优先从用户已有资料读取，只有会阻碍当前任务的信息缺失才提问。

必要信息：受众、内容目标、栏目、篇数、视觉偏好、事实资料位置、交付模式。上传还需要可用的公众号适配器和账号权限；这些缺失不影响先完成独立的研究和本地交付包。

## Eden 公众号日更配置示例

以下是这套流程的历史应用配置，不是所有账号的默认定位。账号当前文件与最新用户要求优先；不自动把其他平台的家长/育儿定位带入公众号。

- 北京时间每天 08:50 开始，使用现有自动任务；默认两篇。
- 固定一篇产品，另一篇行业/AI 营销实操/GitHub 营销精选轮换。
- 示例轮换：周一、三、六行业；周二、五营销实操；周四、日 GitHub。没有合格材料就选择更有价值的栏目。
- 产品可配置为喵了瞄，以专注陪伴、帮助开始现实任务为内容主线；每次核对当前产品事实，不能把愿景写成实现效果。
- 产品采用真人与像素猫，营销实操采用纪实摄影。不要将这种偏好强制给其他账号。
- 第二篇中实操和 GitHub 聚焦 AI 营销；同一工具可持续深挖，但每篇记录新增价值。
- 产出进入草稿箱，正式发布另行审核。发布前的效果指标是待观察项。

## 定时和并发

只有用户明确要求定时运行才创建或修改调度器。已有任务优先更新，检查时区和任务目标；Skill 文件不能使定时任务自行生效。

各栏目可以独立保存材料，统一由一个上传执行者组稿。用账号标识＋日期/批次标识区分运行；同一批次只允许一个上传执行者，避免两个窗口同时创建重复草稿。
